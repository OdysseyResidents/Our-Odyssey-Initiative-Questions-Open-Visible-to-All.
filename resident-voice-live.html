Repeat submissions and partial responses

How repeats are handled: when one respondent ID has more than one submission, the later submission is used. Any answer left blank in the later submission is filled from the earlier one. A submission is partial when fewer than 7 of the key answers are filled in (intention, calculator, co-op, buy-in, commitment timing, deck and cabin category). Each respondent ID is created when someone opens the survey link, so a repeat ID is most likely the same browser session, not necessarily the same person.
